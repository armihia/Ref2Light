# Ref2Light model

This folder contains the project generation model, `ref2light.pt`. Place the entire `model/` folder in the repository root, giving the path `Ref2Light/model/ref2light.pt`.

The file includes the full-body network, local expression networks, mouth-expansion and eyebrow heads, and display calibration. Download Google MediaPipe models separately into `assets/` as described in the repository README.

This inference distribution contains no optimizer state, training data, or third-party pretrained weights.
